# make me better

一个只给自己用的个人空间：**动态**、**学习**、**档案**、**日记**、**相册**。

没有注册、没有别人、没有评论区。文字在 MySQL 里，图片在 `data/uploads`，相册完全靠文件夹。

---

## 现在有什么

| 栏目 | 是什么 |
| --- | --- |
| 首页 `/` | 一张世界树图，五个入口（主页、动态、学习、档案、日记）挂在树枝上 |
| 主页 `/profile` | 头像 + ID + 一句签名 + 四项统计 +「现在」；下面一条相册横条 |
| **动态** `/feed` | 短句 + 最多 9 张图，像 QQ 空间；点图看大图（← → 切换，Esc 关） |
| **学习** `/study` | 长笔记，Markdown；分类（八股/算法，可不选）+ 一个标签，可按分类看、按标签分组 |
| **档案** `/archive` | 一个主题一个档案（一本书、一个游戏），档案只有名字，里面全是条目；条目在整页写作台里写，能插图 |
| **相册** `/album` | 图集 = 文件夹；新图先进「待整理」，在网页上勾选归类，可移动、可进回收站 |
| **日记** `/diary` | 一天一篇，纯文字；只有当天能改能删，过了当天只能看。进去要单独的密码，离开就重新锁上 |
| 管理 `/admin` | 写、改、删、改资料（ID/头像/签名）、改两个密码、管档案 |

整站都在登录后面：连首页都进不去，必须先输用户名和密码。日记在那之后还要再输一次自己的密码。

深色是默认主题，内页右上角可以切浅色。

**服务只监听 `127.0.0.1`**：只有这台电脑能打开，局域网里的手机、别的电脑都连不上（换 WiFi、断网都不影响自己用）。

## 怎么启动

**最简单**：双击 `deploy\start.cmd`（`deploy\open.cmd` 会等启动好后自动开浏览器）。

**手动**：

```bash
mvnw.cmd spring-boot:run
```

打开 http://127.0.0.1:8090 。

第一次打开会自动跳到 `/setup`，设：用户名（就是主页上的 ID）、登录密码（≥8 位）、日记密码（≥4 位）。

## 数据库与图片

| 项 | 值 |
| --- | --- |
| 库 | `make_me_better`（utf8mb4），表结构由 Flyway 管，启动时自动执行 `V1`～`V5` |
| 账号 | `mmb`（只对这个库有权限） |
| 密码 | 在 `application-local.yml`（不进版本库） |
| 图片 | `data/uploads/` 下：`avatars/` 头像、`年/月/日/` 动态配图、`archives/{档案id}/` 档案插图、`albums/` 相册 |

图片**不存数据库**：库里只存相对路径，文件落在磁盘。这样数据库小、备份快、图片加载也快。

**备份要两样都拿**：

```bash
mysqldump -u mmb -p --default-character-set=utf8mb4 make_me_better > 备份.sql
# 再把 data/uploads 整个目录拷走
```

**离线跑**（不想开 MySQL）：`mvnw.cmd spring-boot:run -Dspring-boot.run.profiles=dev`，用本地 H2 文件库。

## 相册怎么用

以文件夹为准，没有数据库表：

```
data/uploads/albums/
  _inbox/         ← 待整理：新图先扔这儿
  旅行/           ← 图集就是子文件夹
    _thumbs/      ← 缩略图（自动生成，删了会重建）
  .trash/旅行/    ← 「移到回收站」的去处，不直接删
```

- **加图**：把图片拷进 `albums\_inbox\`，或者直接拷进某个图集文件夹，刷新网页就出现（不用重启服务）
- **分拣**：打开 `/album`，待整理区勾几张 → 选图集（或填名字新建）→ 归类；背后就是把文件移过去
- **看图**：点缩略图开站内灯箱，× 或 Esc 关
- **删除**：移到 `.trash`，想找回就在资源管理器里把文件移回图集文件夹
- 网页上传也行（一次一张，落到待整理），但批量拖文件更快

原图永远原样保留：上传和归类都不重编码，缩略图是另存的一套文件。

## 平时怎么用

- **发动态**：`/feed` 顶部写两句 → 选图 → 发布
- **写日记**：`/diary` → 输日记密码 →「写今天的日记」；一天一篇，纯文字，换行就换行。
  只有当天写的那篇能改能删，过了当天就只读；离开日记区会自动锁上，下次进来要重新输密码
- **写学习笔记**：学习页右上角「写一篇」；Markdown + 实时预览，Ctrl/⌘ + S 保存，
  写完返回回学习，不会跳回管理页
- **记档案**：管理 → 档案 → 建档案 → 新建条目 → 一整页写作台，写正文、点「插图」放图，保存后留在原页面
- **相册**：见上一节
- **改资料 / 改密码**：管理 → 设置，登录密码和日记密码各一个表单

Markdown 里**一个回车就是换行**（不要求空一行），写笔记时比较顺手。

## 日志怎么读

控制台（`start.cmd` 那个窗口，或 IDEA 的 Run 窗口）里只有两种东西：**启动日志**和**请求日志**。

启动日志长这样，读一遍就知道它在干什么：

```
Tomcat started on port 8090 (http)          ← 服务器起来了
HikariPool-1 - Start completed.             ← 数据库连接池建好了
Migrating schema "public" to version "5"    ← Flyway 跑了第 5 个迁移
Started MakeMeBetterApplication in 6.3s     ← 应用可以用了
```

请求日志是项目自己加的（`config/RequestLogFilter.java`），每处理完一个请求打一行：

```
GET /profile → 200 · 107ms
POST /album/move → 302 · 8ms
GET /nope → 404 · 5ms
GET /setup → 200 · 599ms（有点慢）
```

- `302` 是"重定向"——表单提交成功后跳走，看到它就是保存成功了
- 超过 500ms 会变成 `WARN` 并标「有点慢」，方便发现哪个页面变卡了
- css / js / 图片不记（一个页面会连带请求十几个资源，记下来没法看）
- 首次访问某个页面会慢一点（模板第一次编译），之后就快了，不是问题

**不想看就关掉**：`application.yml` 里把 `app.request-log` 改成 `false`。

**想把日志存成文件**：在 `application.yml` 加一行

```yaml
logging:
  file:
    name: logs/app.log
```

### 拿它练手

1. 打开任意页面，看控制台多出来的一行，对照浏览器地址栏猜它对应哪个请求
2. 点一次「保存」，看 `POST` 那行返回 `302`——这就是"提交后用重定向防止重复提交"（PRG 模式）
3. 手动访问一个不存在的地址（比如 `/nope`），看 `404`
4. 想看更细的分发过程，临时加 `logging.level.org.springframework.web=DEBUG`（很吵，看完记得删）

## 自检

```bash
mvnw.cmd test
```

覆盖：建账号 → 改资料/头像 → 发带图动态 → 空动态被拒 → 建档案/加条目/排序 → 相册上传/归类/进回收站
→ 写学习（含换行渲染） → 日记拦截/解锁 → 改 → 删 → 退出后后台被挡 → 404。

## 常见问题

**端口被占？** 改 `application.yml` 里的 `server.port`。

**连不上数据库？** 先 `Get-Service MySQL80`，再看 `application-local.yml` 在不在项目根目录。

**图片 404？** 看 `data/uploads` 里有没有文件；换过 `app.upload-dir` 的话，旧图路径就对不上了。

**相册里看不到刚拷进去的图？** 刷新那页就行（每次请求都会重新扫目录）。
格式建议 jpg / png / gif；webp 能存进去，但缩略图这一环还没适配；heic 浏览器本身也放不了。

**手机打不开？** 正常情况下就是打不开——服务只绑 `127.0.0.1`，这是有意的。

**页面样式是旧的？** `Ctrl + F5`。

**改完代码没生效？** 项目没有热重载，重启一次。
